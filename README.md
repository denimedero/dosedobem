# Dose do Bem

Notícias boas, checadas e com fonte. Uma dose por dia, em português, español e English.

- `index.html`: o site (página única, sem dependências além das fontes do Google).
- `noticias.json`: a edição do dia, atualizada automaticamente toda manhã.

Idiomas: `?lang=pt`, `?lang=es` ou `?lang=en`.
